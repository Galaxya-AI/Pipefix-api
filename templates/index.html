What to fill in

Project
The address of a GitLab project, on gitlab.com or a self-hosted GitLab. The address of a pipeline page also gives its number.
Pipeline
Optional. Empty: PipeFix takes the latest failed pipeline of the project.
Access code
Given to you by the owner of PipeFix.{% if access_request_email %} Ask for one by email.{% endif %}
GitLab token
Not needed for a public project. A private project needs the read_api scope, and publishing a fix needs the api scope. Used for this run only, never stored.

The buttons after an analysis

Fix until the pipeline passes
Commits the fix, waits for GitLab CI and fixes the new errors round after round. The draft merge request opens only when the pipeline is green.
Create merge request
Publishes this fix alone as a draft merge request, without waiting for the pipeline.
Download patch
Nothing is written to GitLab: apply the patch yourself.
